# Personal website

Static homepage for Diego Petrucci, served by GitHub Pages from `main`.

The homepage preserves the former Tophost site. The wishlist was retired during the migration.

- Edit `index.html` for text and `style.css` for appearance.
- The personal blog is maintained in [diegopetrucci/blog](https://github.com/diegopetrucci/blog) and served under `/blog/`.
- The development blog is a separate Pages project under `/dev/`.
- Do not copy WordPress exports, databases, credentials, or other private backups into this public repository.

Preview locally with `python3 -m http.server 8765 --bind 127.0.0.1`.
